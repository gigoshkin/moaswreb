## Competition tracks

1. **Make it better** — rebuild famous apps as if AI existed from day one.
2. **Multiplayer** — two agents, one shared workspace.
3. **Mobile native** — a real phone app (Lovable-powered).
4. **Desktop native** — native computer app for code-focused engineers.
5. **Solana Ideathon** — side track by Superteam Georgia.

### Track 01 — Make it Better
- Rebuild apps like Facebook, Discord or Airbnb with AI built in from the start.
- Agents post, reply, create and decide the same way people do; **everyone can see who did what**.
- Example ideas: notes app with AI built in, a Finder that understands your files, semantic search inside any app, an email client that sorts and drafts, a calendar that plans your week, a spreadsheet you talk to.
- *"Adding a chatbot to the old app is not enough."*

### Track 02 — Multiplayer Agentic Experiences
- Pitch: Google Docs/Notion let people work together; now **two people work on one thing, each through their own agent**.
- Example ideas: video editing together, game development together, "Agent Git: no commits, no conflicts".
- What they want to see: each agent knows what the other changed; no conflicts, always up to date, "like Figma"; smooth to use.
- **A live demo with two people on stage.**

### Track 03 — Mobile Native
- A real phone application, **not a web wrapper**.
- Lovable builds it for you. Early access: connect Lovable on your profile and check in.
- Example ideas: intelligent camera, voice assistant, smart keyboard.

### Track 04 — Desktop Native
- Native computer applications for developers.
- Example ideas: file explorer (like Finder), launcher (like Raycast), clipboard manager, agent harness, agent browser.
- What they want to see: real access to the computer (files, shortcuts, notifications, other apps); feels native (fast start, keyboard-driven); the user stays in control and approves changes.

### Track 05 — Solana Ideathon (side track)
- Run by Superteam Georgia; you pitch a Solana project idea. The best Georgian ideas go on to the **Colosseum hackathon**.
- Prize pool **1,500 USDG** (750 / 450 / 300).
- Teams of 1–3, open to people in Georgia.
- Superteam's own rules, prizes and judging apply.
- Submit as deck, PDF, Notion or Google Doc.
- Details: superteam.fun/earn/listing/solana-ideathon-hacktoberfest

## Judging

- **Evaluated:** clear problem identification; creative solution approach; problem-solving effectiveness.
- **Not evaluated:** business model, pricing, global expansion strategy.
- **Judges:** "the organizers, tech people, nerds" — the jury judges every project.

**Jury:** Dudu Popkhadze (FLP), Giorgi Bagdavadze (FLP), Avtandil Ushikishvili (DevTherapy), Roman Letodiani (Lovable), Nika Sakandelidze (FLP), Archil Sharashenidze (FLP), Tornike Gomareli (DevTherapy).
